# Changelog

## 0.1.0 - 2026-08-02

- Centralized product identity as Linear.
- Added a dependency-free C++17 image-analysis and CPU graphics core.
- Added RGB/HSV/Lab and motion-assisted detection with scene-cut protection.
- Added deterministic tracking, dropout recovery, and four smoothing modes.
- Added boxes, nine marker shapes, six network topologies, five routes, grids,
  technical paths, repeaters, custom labels, and six region-fill modes.
- Added direct UTF-8 label editing, installed Windows fonts, and styled label
  panels with independent colors.
- Added shape-aware ellipse fill clipping and source-correct Invert/X-Ray/
  Duotone rendering.
- Added Full/Half/Quarter analysis, content-addressed caching, MFR-safe history,
  and broad CPU optimization.
- Added append-only Adobe parameters, categorized native controls, Premiere-aware
  render-path selection, packaging/install scripts, tests, and benchmarks.
- Added public CI, contribution guidance, security reporting, issue templates,
  and release documentation.
