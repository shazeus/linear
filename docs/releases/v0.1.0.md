# Linear v0.1.0

Linear's first public source release introduces a native Windows effect for
Adobe After Effects and Premiere Pro that converts detected image regions into
configurable technical overlays.

## Highlights

- RGB, HSV, and Lab color detection plus motion-aware detection modes.
- Tracked rectangle, corner-bracket, and ellipse regions with configurable
  markers, labels, networks, grids, paths, and shape-confined fills.
- Adaptive, Cinematic, and Predictive smoothing for more stable tracks.
- Direct custom-label editing, UTF-8 text, installed Windows fonts, and
  independently configurable visual colors.
- Full, half, and quarter-resolution analysis with full-resolution output.
- After Effects Multi-Frame Rendering-aware, render-order-independent core.

## Validation

- 43 dependency-free core tests on Debug and Release builds.
- Clean SDK-free Release configuration used by GitHub Actions on Windows and
  Linux.
- Windows x64 Adobe plug-in built with the official After Effects 25.6 SDK.

## Installation

Download `Linear-0.1.0-windows-x64.zip`, verify it with the accompanying
SHA-256 checksum, close Adobe video applications, then extract `Linear.aex` to:

```text
C:\Program Files\Adobe\Common\Plug-ins\7.0\MediaCore\Linear\
```

## Known limitations

- The downloadable binary is unsigned and intended for development/testing.
- Full in-host validation in After Effects and Premiere Pro timelines remains
  pending.
- The binary release currently targets Windows x64 only.
- The Adobe SDK is proprietary, is not included, and must be supplied locally
  to build the Adobe target.
