# Security policy

## Supported versions

Security fixes currently target the latest release on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting feature on the repository's **Security** tab.
Include reproduction steps, affected versions, expected impact, and any known
workarounds.

Do not include Adobe SDK files, proprietary host binaries, private footage,
license keys, tokens, or personal project files in a report.
